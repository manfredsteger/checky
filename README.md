# Checky

Checky ist ein automatisiertes Website-Monitoring-Tool, das regelmäßige Prüfungen über einen headless Browser (Playwright) und KI-gesteuerte Aktionen (Claude Agent SDK) durchführt. Es ermöglicht Nutzern, Flugsuchen, Ticket-Verfügbarkeiten oder Statusseiten deterministisch und ohne externe APIs zu überwachen.
